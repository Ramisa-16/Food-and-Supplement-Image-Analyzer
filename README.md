---
## ✨ Features
- Food item recognition from images
- Supplement identification and info
- Nutritional breakdown per item
- Health insights and recommendations
- Multi-item detection in one image

## 🚀 Getting Started
```bash
git clone https://github.com/Ramisa-16/Food-and-Supplement-Image-Analyzer.git
cd Food-and-Supplement-Image-Analyzer
pip install -r requirements.txt
python main.py --image food.jpg
```
