# Food and Supplement Image Analyzer using Gemini API

This project demonstrates how to use Google's Gemini multimodal models to:
1. Identify food items from images.
2. Extract nutritional information from gym supplement labels.

## Features

- **Food Recognition**: Upload an image of a food item and get the name using Gemini 1.5 Flash.
- **Supplement Label Analysis**: Analyze a supplement label image to extract nutritional information using Gemini 2.0 Flash.

---

## 📦 Requirements

- Python 3.7+
- [Pillow (PIL)](https://pypi.org/project/Pillow/)
- [google-generativeai](https://pypi.org/project/google-generativeai/)
